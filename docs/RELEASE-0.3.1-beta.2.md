# LANCTL 0.3.1-beta.2

Beta técnica en desarrollo sobre la rama `main`. La versión estable anterior
permanece congelada en `stable/0.3.1-beta.1`, en el tag `v0.3.1-beta.1` y en su
GitHub Release con los instaladores originales.

## Cambios destacados

- Referencia web navegable y buscable para launchers, comandos, proyectos,
  plugins y archivos de documentación.
- Distribución configurable del TUI y asignación proporcional de columnas.
- Columna `USERS` basada en referencias de credenciales, sin exponer secretos.
- Políticas de retención para dispositivos desconectados: permanente, sesión u
  olvido, con alcance global o DHCP.
- Documentos internos JSON versionados y migración de formatos anteriores.
- Mejor reconocimiento de flechas y teclas de función en terminales POSIX.

## Estado de publicación

Esta nota describe el trabajo actual de `main`. Los artefactos instalables de
0.3.1-beta.2 se publicarán únicamente al crear el tag y la Release de esa
versión después de superar todas las comprobaciones.
