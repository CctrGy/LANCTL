# LANCTL 0.3.4-alpha.7 — Experimental (no estable)

Punto de referencia local del 12 de noviembre de 2026 con las últimas
correcciones de desarrollo, posteriores al punto `0.3.4-alpha.3`.

Incluye los ajustes actuales de edición y disposición física, perfiles de
puertos, entrada de fibra, tomas de alimentación, visibilidad del inventario,
grupos, guardado de proyectos e interfaces web de la suite.

La numeración se sincroniza en la aplicación, Clink, documentación activa,
metadatos de Windows y scripts de compilación. Las notas anteriores conservan
su versión histórica.

Este punto no declara una versión estable ni certifica instaladores nuevos.
La compilación y la validación manual multiplataforma quedan pendientes.
