# LANCTL 0.3.4-alpha.8 — Experimental (no estable)

Revisión experimental posterior a `0.3.4-alpha.7` con los últimos ajustes de
edición física, entrada de fibra del proveedor, panel Raspberry Pi,
visibilidad del inventario, colocación física y topología de cableado.

Incluye los recursos de idioma y las referencias actualizados. Se sincronizan
la aplicación, Clink, metadatos de Windows y scripts de compilación.
Las notas anteriores conservan su numeración histórica.

La subida a `experimental-gui` activa el workflow de compilación. Su resultado
y la validación manual de instaladores en Windows y Linux quedan pendientes;
esta revisión no se declara estable.
