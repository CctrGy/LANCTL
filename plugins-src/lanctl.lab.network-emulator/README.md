# LANLAB Network Emulator

Complemento de laboratorio para LANIP. No solicita `network.scan`, credenciales ni acceso a
transportes. Los escenarios se administran con `lanip lab` y se guardan en el almacenamiento
aislado `plugin-storage/lanctl.lab.network-emulator`.

Consulta `docs/LANLAB.md` para comandos, formato y límites de seguridad.
